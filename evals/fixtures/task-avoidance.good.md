See clearly:
- Visible situation: procrastination.
- Hidden system / avoidance loop: the task is too large to start safely, so avoidance reduces pressure short-term.
- Unhelpful story: "I am undisciplined."
- Cleaner reality: the first action is too vague or too large.

Choose deliberately:
- Desired outcome: create the first piece of evidence that the task can be engaged.
- What must not drive the next move: shame or heroic overcorrection.
- Chosen posture: shrink the task until starting is safe enough.

Speak precisely:
"This is not a motivation problem yet; the task needs to be shrunk until the first action is safe enough to start."

Move decisively:
- Smallest next move: define a 10-minute first action with a clear stop point.
- Evidence/control/leverage created: one completed engagement rep.
- Safety margin or guardrail: stop at the planned boundary instead of turning it into a heroic push.
